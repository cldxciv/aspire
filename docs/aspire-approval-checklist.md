# Aspire homepage: approval checklist

Prepared 20 October 2026 for Aspire IIT & Medical staff by the website team.

## How to use this checklist

The new homepage is built. Most of the information on it came from two places: Aspire's demo website (aspire2.thechunkmedia.com) and the web team's own wording. That includes numbers, results, names, centre details and quotes. **Nothing in this list will be published as fact until Aspire approves it.**

**Where each item appears:**

- **Preview only.** The item appears only on the private review version of the website, always with a yellow **DEMO** label. It is hidden on the public website.
- **Live site.** This is general wording that will be on the public website as soon as it launches. **Please answer these items first.**

**Please choose one decision for each item:**

| Decision | Meaning |
|---|---|
| **Approve** | The value is correct and can be published exactly as shown. |
| **Correct** | Give us the right value. For numbers, results, credentials and addresses, please also send evidence, such as an official scorecard, allotment letter, certificate, registration document or utility bill. |
| **Omit** | Leave it off the website. |

**Names and photos need written permission.** Any item that names a student, parent or teacher also needs written permission from each person named. If the student is under 18, a parent or guardian must also give permission. Approving the wording is not enough on its own.

**Conflicts C1–C45.** A conflict means the demo website, or the design images, gives two or more different values for the same thing, and we need you to tell us which one is right. Each conflict is included as a question below. All 45 are also listed in [Appendix A](#appendix-a-all-conflicts-c1c45), with the item that answers each one.

The **Reference** column is for the web team only. You can ignore it.
