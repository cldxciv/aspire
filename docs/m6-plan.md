# Milestone 6 — student tools (multi-agent plan)

Owner request 2026-10-20: build four student tools ASAP with multiple agents: (1) rank & college predictor, (2) CBT mock-test engine with leaderboards, (3) "Ask Aspire" AI doubt solver (English + Hindi), (4) smart study planner with spaced revision and streaks. Base commit `fef165f`.

## Decisions (binding for every M6 agent)
- **D-032 Honest tools.** No invented facts, scores, ranks, cutoffs or outcomes. The 715 rankers have name, college, exam and year — **no scores** — so nothing may say "students with similar scores got X". Sample content (questions, cutoff/score-band tables, formulas, study-plan templates) is `status: "placeholder"`, labelled "Sample" / DEMO, shown only when `showPlaceholderContent()` is true (dev / demo mode), until Aspire supplies or approves it. Real Aspire data may be used as-is with its existing visibility rules (rankers → "where Aspire students got in").
- **D-033 No fake channels.** There is no WhatsApp, SMS, email or push provider. Never claim a report or reminder was "sent"; show an honest "not connected" note and put reports where they really are (the parent portal, a downloadable file, an `.ics` calendar export). Lead capture = link to the existing enquiry form (`/admissions#enquiry`), no new contract.
- **D-034 Students' data.** Many users are minors. Guests' data stays in their browser (`localStorage`); signed-in students' data goes to SQLite (`src/lib/db/features/<feature>.ts`, idempotent `CREATE … IF NOT EXISTS`, tables prefixed with the feature). Leaderboards are opt-in, signed-in only, and show a pseudonymous display ("First name + initial" or a chosen nickname), never login IDs, schools only if the student opts in. Parents see only their linked learners (existing record-level rules). Uploaded photos for Ask Aspire are processed in memory and never stored. Every new data flow gets a line in the privacy notice (lead).
- **D-035 AI doubt solver.** Server-side only (`ANTHROPIC_API_KEY`, never sent to the browser); model configurable by env; without a key the page shows "not connected". Academic help for Physics, Chemistry, Maths, Biology only; step-by-step; answers in the student's language; no claims to use Aspire's notes or NCERT text unless that material is actually provided; safety rules for minors; per-IP / per-student daily limits; cost caps (max tokens, image size).

- **D-036 MCP server (owner request).** The site exposes `/api/mcp` (Streamable HTTP, official SDK, stateless) for Claude agents. Admin-issued bearer tokens only (SHA-256 stored, expiry ≤ 365 days, revocable, paused when the creating admin is disabled or on a temporary password), read vs read+write scopes, per-token and per-IP rate limits, every call audited without arguments. Admin tokens may read learner progress as counts/labels only (`get_student_progress`); no password-reset, admin-creation or enquiry tools. `/api/mcp` is exempt from the preview Basic-auth gate (it has its own bearer auth). claude.ai custom connectors need OAuth — not implemented. Docs: `docs/mcp.md`.
